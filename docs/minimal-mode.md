# Minimal 模式设计方案

本文档记录 `pi-path-bar` Minimal 模式的信息架构、横线分区规则、极简编码规范、扩展三分类策略及降级机制。

Minimal 模式**默认开启**，可在 `/path-bar` 设置页通过 `Minimal mode`（`On` / `Off`）一键切换与还原，不新增独立命令。

---

## 1. Pi 输入栏横线原生占用与核心原则

在 Pi 1.5.x 中，`CustomEditor`（`embedWorkingStatus: true`）与 `Editor` 对输入框上下横线的原生占用分布如下（以 80 列终端为例）：

```text
符号说明：
  W = 常态运行指示占用 (第 1..13 列，默认 `── ⠋ Working `)
  L = 罕见长提示扩展区 (第 14..70 列，重试 / 压缩 / 分支摘要)
  S = 滚动提示偶发占用 (居中 10..13 列，` ↑ N more ` / ` ↓ N more `)
  . = 原生完全空闲

                 1         2         3         4         5         6         7         8
        12345678901234567890123456789012345678901234567890123456789012345678901234567890
上横线：WWWWWWWWWWWWWLLLLLLLLLLLLLLLLLLLLLSSSSSSSSSSSLLLLLLLLLLLLLLLLLLLLLLLLL..........
下横线：..................................SSSSSSSSSSS...................................
```

基于该空间特征，Minimal 模式确立 **4 条核心原则**：

1. **上横线 W 区恒定降级为 5 列（方案 B，零抖动）**：
   - 常规运行态（`kind === "working"`）固定渲染 `── ⠋ `（5 列），不再展开 `Working` 文本。
   - 空闲且上左有内容时渲染 `──── `（5 列），与运行态列位严格对齐，状态切换零抖动；空闲且上左无内容时为连续横线 `─`，不留多余空格。
2. **上横线 L 区复用**：
   - 重试（`retry`）、上下文压缩（`compaction`）、分支摘要（`branchSummary`）等长提示不常见。
   - 平时 L 区放置非即时关注信息（用量遥测、会话名）；罕见长提示触发时直接接管 L 区，结束后自动恢复。
3. **S 区按需居中覆盖**：
   - 多行输入滚动提示（` ↑ N more ` / ` ↓ N more `）仅在用户输入长文本时出现，平时不预留空白；出现时按列宽居中叠加覆盖（正确复位 ANSI 序列并处理宽字符边界），退出滚动后立即还原。
4. **重写边框钩子保护自动补全**：
   - `MinimalEditor` 继承 `CustomEditor` 并重写 `renderTopBorder` 与 `renderBottomBorder`，不改写 `lines[lines.length - 1]`，确保 `/`、`@` 自动补全菜单渲染在下横线下方且不被覆盖。

> 字符宽度约定：所有内置极简符号均选用 `visibleWidth === 1` 的 BMP Unicode 或项目现有 Nerd Font 图标（`\uf07c`、`\ue0a0`），避免双宽 Emoji 在不同终端中的对齐偏差。

## 2. 上下横线四槽位分配

| 区域 | 定位 | 放置内容 |
| :--- | :--- | :--- |
| **上横线 · 左（W + L）** | 瞬时运行态 + 非即时信息 | • W 槽（5 列）：运行 spinner `⠋`（空闲为 `──── `）<br>• L 槽（平时）：精简 Token 用量、缓存命中率、费用/订阅、会话名<br>• L 槽（异常态）：原生重试 / 压缩 / 分支摘要提示临时接管 |
| **上横线 · 右** | 外围与扩展槽位 | • 类型 2 主动注册扩展（`path-bar:<id>`）<br>• 类型 1 内置适配扩展（`ponytail`、`ssh`、`preset`、`usage`、`debug-provider`）<br>• 本机时间 `clock`<br>• 宽度不足时按顺序从右侧折叠为 `+N` |
| **下横线 · 左** | 工作区安全锚点（即时关注） | • 文件夹图标 + 极简路径（含目录别名高亮）<br>• 紧凑 Git 状态（分支、操作态缩写、无空格计数，沿用主题状态色） |
| **下横线 · 右** | 模型与上下文窗口（即时关注） | • 缩写模型名 + 单字母思考等级（`off` 省略）<br>• 上下文占比仪表符号 + 整数百分比 / 窗口上限（默认 `◐42%/200k`，窄屏降级为 `◐42%`，带 70%/90% 预警色） |
| **下横线下方一行** | 类型 3 未知扩展（按需显隐） | • 未适配且未主动注册的普通 `setStatus(key, text)`<br>• 无内容时返回 `[]`（0 行，彻底隐藏） |

## 3. 全量字段极简编码规范

### 3.1 下横线 · 左（工作区上下文）

| 信息项 | 标准极简态 | 超窄降级态 | 规则与颜色 |
| :--- | :--- | :--- | :--- |
| 目录路径 | ` ~/P/pi-path-bar`（优先别名） | ` pi-path-bar` → `pi-path-bar` | 遵循 `config.mode` 与 `config.icon`；别名使用 `mdLink` 色 |
| Git 分支 | `feat/minimal` | `feat/min…` → 隐藏 | 遵循 `config.branch`；沿用 `gitColor`（`mdLink` / `warning` / `error`） |
| Git 进行中操作 | `R2/5` / `M` / `CP` / `RV` / `BS` / `AM` / `AR` | 同左（1~4 列） | 对应 rebase / merge / cherry-pick / revert / bisect / am |
| Git 计数 | `⇣1⇡2*1~1+2!3?4`（去空格） | `⇣⇡*~+!?`（去数字）→ 仅靠分支颜色 | 按 `behind / ahead / stash / conflicted / staged / dirty / untracked` 顺序拼接 |

### 3.2 下横线 · 右（模型、推理与上下文）

| 信息项 | 标准极简态 | 超窄降级态 | 规则与颜色 |
| :--- | :--- | :--- | :--- |
| 模型名 | `sonnet-4.5` / `gem-2.5p` / `gpt-5.2c` / `ds-r1` | `s4.5` / `g2.5p` / `g5.2c` / `ds-r1` | 自动剥离日期戳与 `-latest`/`-preview`/`-instruct`/`-chat` 后缀 |
| Thinking level | `off` 省略；其余 `·m` / `·L` / `·M` / `·H` / `·X` | 省略（边框色本身已体现等级） | 跟随当前 `borderColor` |
| 上下文占比 | `◐42%/200k`（未知 `○?/200k`） | `◐42%`（未知 `○?`） | `0%` `○`、`1-33%` `◔`、`34-66%` `◐`、`67-89%` `◕`、`≥90%` `●`；`>70%` `warning`、`>90%` `error` |

### 3.3 上横线 · 左（W 槽 + 非即时遥测与会话）

| 信息项 | 标准极简态 | 超窄降级态 | 说明 |
| :--- | :--- | :--- | :--- |
| 运行态（W 槽） | `── ⠋ `（5 列） | `── ⠋ `（永不缩减） | 空闲有左内容时为 `──── `（5 列） |
| Token 用量 | `↑12k ↓4k` | 隐藏 | 千位取整，省略 R/W 细分；为 0 时隐藏 |
| 缓存命中率 | `c85%` | 隐藏 | 整数百分比；无缓存读写时隐藏 |
| 费用 / 订阅 | `$0.12` / `$.004` / `$0.12ˢ` / `sub` | 隐藏 | 订阅制零费用显示 `sub`，有费用追加上标 `ˢ` |
| 会话名 | `·refactor`（上限 12 列） | 隐藏 | 遵循 `config.session` |

### 3.4 上横线 · 右（时间与扩展三分类）

| 信息项 | 极简形态 | 说明 |
| :--- | :--- | :--- |
| 本地时钟 `clock` | `14:50`（24h）/ `2:50p`（12h） | 遵循 `config.timeFormat`，支持在 `Footer order` 按 `Space` 隐藏 |
| 类型 2：`path-bar:<id>` | 原样显示（保留颜色） | 扩展主动注册的槽位，优先级高于同名类型 1 |
| 类型 1：`ponytail` | `♘L` / `♘F` / `♘U` / `♞L` / `♞F` / `♞U` / `♘-` | `♘`（U+2658 空心马）表待命/OFF，`♞`（U+265E 实心马）表激活，strict 2 列宽，保留原前缀色 |
| 类型 1：`ssh` | `ssh:<host>`（≤14 列） | 提取远程主机名，保留原前缀色 |
| 类型 1：`preset` | `P:<name>`（≤12 列） | 压缩预设名称，保留原前缀色 |
| 类型 1：`usage` | 去除 `left` 等冗余词（≤14 列） | 例：`5h:100% left` → `5h:100%` |
| 类型 1：`debug-provider` | `dbg` | 兼容 `debug-provider` 与 `provider-debug` |
| 类型 3：未知扩展 | 不占上横线，在下横线下方单独 1 行显示 | 无未知扩展时彻底隐藏（0 行） |

- **排序与隐藏**：在 `/path-bar` → `Footer order` 中，`< / >` 调整顺序，`Space` 切换显示/隐藏（覆盖 `clock`、类型 1 和类型 2，持久化于 `hiddenSegments`）。被隐藏的类型 1 扩展不会回流到下横线下方一行。
- **溢出折叠**：上横线右区装不下全部未隐藏槽位时，按配置顺序从右侧弹出并追加 `+N` 徽标。

## 4. 窄屏渐进降级优先级

### 下横线淘汰顺序（从最先舍弃到最后保留）
1. 路径父级目录（`~/P/pi-path-bar` → `~/…/pi-path-bar` → `pi-path-bar`）
2. Git 计数数字（`+1!2` → `+!`）
3. 上下文窗口上限（`◐42%/200k` → `◐42%`）与模型二次缩写（`sonnet-4.5` → `s4.5`）
4. Git 计数符号（仅留分支名与状态色；超长分支名截断）
5. 思考等级字母（`·H` → 省略，由边框色兜底）
6. Git 分支（整体隐藏）
7. **最后死保**：`末级目录` + `超短模型名` + `◐42%`

### 上横线淘汰顺序（从最先舍弃到最后保留）
1. 会话名（`·refactor`）
2. 缓存命中率（`c85%`）
3. Token 摘要（`↑12k ↓4k`）
4. 费用 / 订阅（`$0.12`）
5. 上右槽位从右向左折叠为 `+N`（极端窄屏隐藏）
6. **最后死保**：5 列运行 spinner `── ⠋ ` 或异常态长提示

## 6. 实现文件映射

| 文件 | 职责 |
| :--- | :--- |
| `src/config.ts` | `minimal`（默认 `true`）与 `hiddenSegments` 配置校验和持久化 |
| `src/segments.ts` | 扩展三分类 `classifyStatuses()` 与类型 1 内置适配器注册表 `ADAPTED_EXTENSIONS` |
| `src/minimal.ts` | 极简格式化器、`+N` 折叠、S 区按列覆盖、上下横线排版引擎与 `MinimalEditor` |
| `src/index.ts` | 会话用量缓存、Minimal 模式与标准/原生模式生命周期切换、按需显隐 Minimal Footer |
| `src/settings.ts` | `/path-bar` 的 `Minimal mode` 开关与 `Footer order` 排序/隐藏界面 |
| `test/minimal.test.ts` | 格式化、三分类、`+N` 折叠、零抖动、宽字符 S 覆盖、0..120 列不变量及开关还原测试 |
